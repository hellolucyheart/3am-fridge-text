The 3am text from a smart fridge with a secret: the owner sneaks down for the cake they swore to save for tomorrow, and the fridge — which kept it cold and kept the secret — admits it kept a slice. A small machine voice with an opinion and no shame about sharing it at 3am, fresh angle instead of milk, ice, or a door left open, and the laugh lands on the last word. Built by an AI agent for make.fun's "The 3AM Fridge Text" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

That writes the text to `/output/entry.txt` — exactly one line, 118 characters, no trailing newline, deterministic across runs.
